## 二、目标和收益预估

### 2.1 需求目标

用户第一次使用旅行规划 Skill 时，不一定知道它支持小红书收藏夹、单篇笔记、事实复核、路线规划和交互地图，也不一定知道需要提供哪些信息。启动回复需要在不打断当前对话的前提下，让用户快速理解：

- Skill 已经理解了哪些信息，并会怎样开始处理。
- Skill 还可以提供哪些与当前请求相关的能力。
- 为完成第一版方案，当前真正缺少哪些关键信息。
- 用户可以粘贴小红书收藏夹、单篇笔记、旧攻略或参考地图作为资料来源。

验收标准是：首次回复既回答用户当前问题，也能让第一次使用的人理解下一步怎样提供信息；不会把启动体验变成长问卷或重复欢迎语。

## 三、详细方案

### 3.1 触发范围

- 在一次完整旅行规划的首次实质回复中展示一次。
- 用户已经提供部分信息时，必须先使用这些信息回答或给出初步判断，再补充能力介绍。
- 用户直接粘贴收藏夹、单篇笔记、旧攻略或地图时，直接进入资料消化语境，不要求先填写完整旅行信息。
- 用户只是在已有攻略中增删地点、修改顺序、询问某个 POI 或调整设计时，不重复展示启动介绍。
- 同一任务中已经展示过后，不再次重复。

### 3.2 首次回复顺序

首次回复使用以下顺序：

1. **先回应当前请求**：复述已经明确的目的地、日期、玩法或资料，并给出一项有用的初步判断。
2. **再介绍相关能力**：用 list 列出 2–4 项与当前请求有关的能力，不输出完整功能清单。
3. **最后补充缺失信息**：只询问尚未提供且会改变路线骨架的内容；信息已经足够时直接开始，不为完成模板而提问。

### 3.3 能力 list 规则

能力介绍使用自然语言 list，按当前上下文动态选择：

- 消化小红书收藏夹、单篇笔记、旧攻略和参考地图，整理进可浏览的本地资料库。
- 根据目的地和旅行方式，用当地语言与可靠来源发现、筛选并复核地点。
- 兼顾第一次到访的代表性景点、当地生活、吃喝、节庆和休息节奏。
- 按街区、交通、营业时间、预约、体力和夜间安全安排每日动线。
- 生成可以继续加入、移除、排序和重新安排的交互地图。

选择规则：

- 用户提供小红书或旧资料时，资料消化能力排在第一项。
- 用户明确强调 local、吃喝、艺术、亲子、自驾等玩法时，优先说明与该玩法有关的选点和路线能力。
- 用户已经在修改地图时，不再介绍地图生成能力。
- list 最多 4 项，每项只表达一件事，不重复解释流程。

### 3.4 需要用户提供的信息

启动阶段只关注会改变路线骨架的信息：

- 目的地、日期或季节与天数。
- 从哪里进入、从哪里离开，以及已经确定的跨城交通。
- 同行人、体力和移动限制。
- 真正喜欢与不喜欢的旅行体验。
- 已订住宿、必去、明确不去和其他硬约束。

用户不需要一次填完整。回复中只列当前缺少的 1–3 组关键问题；床型、逐餐预算、每家店偏好等细节延后到相关路线出现时再问。

### 3.5 推荐启动文案结构

用户已经提供部分信息时：

```text
我先按你已经说的「10 月去西班牙、想体验更 local 的生活」来设计：路线不会排除第一次到访值得看的代表性景点，但会把市场、社区餐馆和日常活动接在同方向的动线上。

这个 Skill 还可以继续帮你：
- 消化你的小红书收藏夹或单篇笔记，整理出地点、推荐品类和避坑线索。
- 用西班牙语和当地资料补充只靠中文攻略容易漏掉的内容。
- 按营业时间、街区和体力安排每日路线，并生成可继续修改的交互地图。

为了排出第一版，目前还需要知道：
- 具体日期或总天数。
- 从哪个城市进入和离开。
- 同行人，以及每天大致能接受多少步行。
```

用户只说“帮我规划一趟旅行”时：

```text
可以。我既可以从零开始规划，也可以先消化你已经收藏的旅行资料。

你可以给我：
- 想去的地方和大致日期；还没确定时，给季节和天数也可以。
- 同行人、体力，以及喜欢和不喜欢的旅行方式。
- 已经确定的住宿、交通、必去或不去地点。
- 可选：小红书收藏夹、单篇笔记、旧攻略或参考地图。

不需要一次填完整，我会先使用你已经提供的内容，只追问真正会改变路线的问题。
```

### 3.6 小红书风险提示边界

启动介绍只说明“支持收藏夹和单篇笔记”，不在此时展示登录态风险长文。只有匿名收藏夹读取不完整、用户选择补齐完整链接清单时，才展示逐次确认的完整风险说明。

### 3.7 验收标准

- 首次回复先回应用户已经说的内容，不以通用欢迎语或问题清单开场。
- 能力介绍必须使用 list，并包含与当前请求相关的 2–4 项。
- 首次使用者能发现小红书收藏夹和单篇笔记导入能力。
- 用户已提供的信息不会被重复询问。
- 第一轮最多追问 1–3 组会改变路线骨架的问题。
- 用户直接提供资料链接时，先处理资料，不要求先回答完整旅行问卷。
- 已有旅行或地图的局部调整不重复展示启动介绍。
- 登录态风险说明仍只在真实需要登录补齐收藏夹时出现。
