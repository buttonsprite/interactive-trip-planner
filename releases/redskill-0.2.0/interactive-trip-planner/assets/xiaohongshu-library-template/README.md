# 小红书旅行资料库

这是保存在你本地的私人旅行资料库，用来整理你主动提供的小红书收藏夹或单篇笔记。

从 [INDEX.md](INDEX.md) 开始浏览。它会链接到：

- `collections/`：按收藏夹查看导入进度和笔记。
- `notes/`：每篇笔记的阅读页、结构化记录和经你允许保存的素材。
- `imports/`：每次导入的成功、重复、失败和停止原因。
- `trips/`：某次旅行采用、候选、忽略和待复核的笔记。

`record.json` 是程序使用的唯一事实记录，旁边的 `note.md` 是自动生成的阅读视图。不要直接修改自动生成的 Markdown；个人判断应写入记录中的 `userState` 或 `userNotes` 后重新生成。

## 隐私与发布边界

- 整个资料库默认不进入 Git，也不会被复制到 REDSkill、公开地图或 Taste Model 贡献包。
- 不保存 Cookie、Authorization、浏览器账号、`xsec_token`、分享追踪参数或带签名的媒体直链。
- 素材默认不下载；只有你明确要求保留或 OCR 必需时，才会保存到对应笔记的 `media/`。
- 小红书内容是发现、推荐与体验线索。营业时间、价格、票务、交通、安全和当期活动仍需官方来源复核。

## 迁移与备份

迁移时复制整个 `travel-library/xiaohongshu/` 目录。目录内部全部使用相对链接，不依赖原电脑的绝对路径。不要只移动某个 `notes/` 子目录，否则收藏夹、导入批次与旅行选集的链接会不完整。
